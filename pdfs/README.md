# Project PDFs

Put downloadable PDF resources for the project sections in this folder.

The current catalog expects:

- `diy-robot-kit-build-notes.pdf`
- `diy-robot-kit-project-checklist.pdf`
- `mandala-coaster-art-project-notes.pdf`
- `mandala-coaster-color-planner.pdf`

To add another PDF later, copy a `pdfs` entry in `src/App.tsx`, change its `title`, `source`, and `description`, then place the matching file here.
